# MF210 계수 유지: 40 km/h 안정영역 최종 근사 코드

정상 타이어, 속도 40 km/h 고정, μ=0.85, 조향각 0°/3.5°/7°를 비교합니다. 외부 보조 함수 없이 실행하는 단일 파일은 **`run_mf210_final.m`**입니다. 기본 MATLAB R2016b 이상을 대상으로 작성했으며 별도 툴박스는 필요하지 않습니다.

```matlab
% 세 조건의 전체 초기상태 격자와 5초 시뮬레이션 실행
run_mf210_final('my_results', true)

% 설치/구문 확인용 소규모 실행: 전체 결과를 대신하지 않습니다.
run_mf210_final('smoke_results', false, true)

% 이미 받은 MAT 세 개를 다시 그리기: 재시뮬레이션하지 않습니다.
plot_mf210_final('MAT_파일_세개가_있는_폴더')
```

전체 실행은 조건마다 81×55×31=138,105개 초기상태를 계산하므로 시간이 걸립니다. 격자는 `vc=-10:0.25:10`, `r=(-27:27)*(0.8/30)`, `phi=(-15:15)*(0.8/30)`이며 기존 점을 보존하고 vc를 세분화했습니다. p(0)=0, 5초 관측, 관측 간격 0.01초, RK4 내부 간격 0.0005초입니다.

기존 210개 코드의 MF 계수·하중 민감도·힘 오프셋·마찰 타원과 μ/0.9 배율을 유지합니다. 5상태 차체, 순간 바퀴 슬립각, 원래 MF의 `Fx=0` 자유회전 근 `kappa=-Shx`를 사용합니다. 기존 Full-Car의 타이어 완화·휠 회전 과도상태 전체를 유지하는 모델은 아닙니다. 차체는 논문 식 (2)~(4)를 사용하며, 수직하중에는 `D_paper-Ixx*pdot`의 동적 롤 반력 확장을 사용합니다. 논문의 Burckhardt 타이어와 인쇄된 식 (11)을 그대로 실행한 결과라는 뜻은 아닙니다.

이번 최종 정리에서 물리 모델과 원시 판정은 바꾸지 않았습니다. 영역 선택만 독립적인 안정 셀 기반 방식으로 확장했습니다. 자기 평형점 주변 안정 연결성분에서 기울기를 추정하고, 각 yaw 구간에서 영 기울기와 그 추정 기울기의 격자 정수 후보를 비교합니다. 영역 내부와 양의 부피로 겹치는 물리 격자 셀은 8개 모서리 점이 모두 안정이어야 합니다. 불확실한 셀의 보수적인 투영 범위와 겹치는 후보를 제외하며, 외부 인접 셀이 경계에 닿기만 하는 것은 허용합니다. 그 **한정된 후보군 안에서 부피 최대**를 선택합니다. 모든 기울어진 육면체를 통틀어 최적이라는 주장은 아닙니다.

동률은 `[vc0,vc1,r0,r1,phi0,phi1,vc_shift,phi_shift]` 격자 인덱스 사전순으로 처리합니다. 다른 조향각의 영역, 목표 그림, 롤 폭, 포함관계는 목적함수나 제약에 들어가지 않습니다. 조향각별 좌표 이동·축소를 적용하지 않습니다.

배포 MAT에는 원시 결과 `PAPER_STABILITY3D`, 선택 영역 `INNER_REGION`, 평형점 `EQUILIBRIUM`, 추가 검증 `GEOMETRY_VALIDATION`이 들어 있습니다. 0°/3.5°는 영 기울기가 선택됐고, 7°는 yaw 방향의 롤 기울기가 선택됐습니다. 선택된 롤 폭은 0.346667/0.293333/0.213333 rad이며 세 영역의 완전한 포함관계는 성립하지 않습니다. 전체 원시 안정점의 롤 극값은 세 조건 모두 ±0.186667 rad입니다.

전체 동역학 계산은 M-code와 대조한 Native C++로 완료했습니다. M-code 및 새 영역 선택 함수는 GNU Octave 9.4에서 검증했으며, 실제 라이선스 MATLAB 실행을 했다는 주장은 아닙니다. 새 함수의 24개 작은 마스크와 전체 3개 마스크 결과가 C++와 일치했습니다. 모든 원시 불안정점 배제, 꼭짓점·내부 표본 재시뮬레이션, 시간 간격 세분화와 별도의 촘촘한 초기상태 검사를 통과했습니다. 이 검사는 유한시간 표본 검증이며 연속 영역 전체의 수학적 안정성 증명은 아닙니다.

`source/`에는 실제 사용한 수치 모델과 Native C++ 소스가, `provenance/`에는 이전 버전과의 동역학 코드 동일성 및 새 M-code 검증 기록이 있습니다. 이전 결과는 별도 폴더에 보존했습니다. 논문 Figure 6의 완전한 재현보다 **기존 MF를 유지한 명시적 근사**로 해석해야 합니다.
