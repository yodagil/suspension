# MF 유지 · 논문 식 (11) · §3.1 극값 추출 기준선

기존 MF 계수는 유지하고, 이전 버전의 동적 롤 반력 확장을 제거한 별도 기준선입니다. 기존 코드와 결과는 덮어쓰지 않습니다.

단일 파일 **`run_mf210_eq11_baseline.m`**에는 필요한 함수가 모두 들어 있습니다. 기본 MATLAB R2016b 이상을 대상으로 작성했으며 별도 툴박스는 필요하지 않습니다.

```matlab
% 전체 세 조건 계산 및 결과 그림 저장
run_mf210_eq11_baseline('my_eq11_results', true)

% 소규모 실행 확인: 전체 결과를 대신하지 않습니다.
run_mf210_eq11_baseline('smoke_results', false, true)

% 이미 저장된 MAT 세 개 다시 그리기
plot_mf210_eq11_baseline('MAT_파일_세개가_있는_폴더')
```

## 조건과 바뀐 점

- 속도 40 km/h 고정, μ=0.85, 정상 타이어, 조향각 0°/3.5°/7°입니다.
- 현재 비교와 같은 `vc=-10:0.25:10`, `r=(-27:27)*(0.8/30)`, `phi=(-15:15)*(0.8/30)` 격자를 사용합니다. 81×55×31=138,105개/조건이며 저자 원래 격자로 확인된 값은 아닙니다.
- 초기 롤레이트 p(0)=0, 5초, 0.01초 관측, RK4 내부 간격 0.0005초입니다.
- 기존 MF 계수·하중 민감도·힘 오프셋·마찰 타원·μ/0.9 배율은 유지합니다. 실제 피크를 μFz로 재정규화하지 않습니다.
- 논문에 인쇄된 식 (11)의 하중이동 모멘트 **`D=m*h*ay+ms*g*hphi*sin(phi)`**를 사용합니다. 이전의 `-Ixx*pdot` 항과 하중 지연 상태는 없습니다.

MF 힘이 수직하중에 의존하므로 매 RHS 평가에서 `ay=Fy(Fz(ay))/m`을 함께 풉니다. 같은 시점의 가속도가 하중식과 차체식에 들어가며 잔차 허용치는 2e−10 m/s²입니다. 빠른 경로는 잔차를 만족한 secant 근을 사용합니다. 실패하면 원래 MF의 100 N 활성화·16000 N 클리핑 경계를 나누어 근을 찾습니다. 다중 근·불연속 때문에 해가 확인되지 않은 경우는 수치 미해결로 남깁니다. 빠른 경로가 모든 상태에서 전역 유일근을 증명한다는 주장은 하지 않습니다. 상세 분기 규칙은 `provenance/solver_contract.json`에 있습니다.

영역 추출은 논문 §3.1 순서인 **롤 극값 → 횡속도 내·외 극값 → 8개 극점 → 내부 후보 검증**으로 구성했습니다. 최대 부피 목적함수와 평형점 포함 조건은 제거했습니다. 조향각별 롤 제한·좌표 이동·축소·강제 포함은 사용하지 않습니다. 논문에 없는 격자 분기·꼭짓점 동률 처리는 [GEOMETRY_METHOD.md](GEOMETRY_METHOD.md)에 명시했습니다.

8개 극점 후보가 모든 비안정·미해결 격자점을 배제하는 유효 육면체로 확인되지 않으면 `INNER_REGION.valid=false`로 저장합니다. 다른 도형을 대신 골라 성공으로 표시하지 않습니다. 실패 후보는 `SECTION31.inner_candidate`와 `INNER_REGION.candidate_vertices`에 남고, 유효 내부 부피 `INNER_REGION.inner_volume`은 NaN입니다. 원시 시뮬레이션 결과는 별도로 보존됩니다.

롤 격자 끝 ±0.4 rad까지 안정점이 있으면 `SECTION31.roll_domain_censored_slices`에 기록합니다. 이는 물리적 롤 한계를 찾았다는 뜻이 아닙니다. 수치 미해결점도 물리적으로 불안정한 점과 따로 저장합니다.

## 검증 범위와 가정

Native C++와 MATLAB 호환 M-code의 RHS·RK4 스텝·소규모 궤적 판정이 일치했습니다. 새 영역 추출은 33개 합성 사례에서 Python과 M-code를 대조했습니다. 단일 파일도 다른 보조 파일 없이 소규모 실행을 통과했습니다. 검증 런타임은 GNU Octave 9.4이며 실제 라이선스 MATLAB 실행을 했다는 주장은 아닙니다.

논문은 Burckhardt 타이어를 사용합니다. 여기서는 MF와 준정적 자유회전 `kappa=-Shx`, 실제 바퀴 속도의 순간 슬립각을 사용합니다. 현가질량 `ms=m=1300 kg`, 롤 암 `hphi=h=0.54 m`, 속도 유지 방식, 초기 p=0와 5초 판정은 명시적 가정입니다. 요레이트 한계 `0.85*mu*g/u`는 논문의 이상 요레이트 식 (13)을 분류에 재사용한 해석이며, 저자의 실행 가능한 안정 판정 코드로 확인된 것은 아닙니다.

따라서 이번 자료는 **MF를 유지하면서 식 (11)과 §3.1 절차를 복원한 기준선**입니다. Figure 6의 완전한 수치 재현을 보장하지 않습니다. `source/`에는 실제 Native C++ 엔진과 M-code 모듈이 들어 있습니다.
