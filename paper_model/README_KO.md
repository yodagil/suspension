# Xiao et al. 2022 논문 기반 독립 MATLAB 재구성 — 실행 검증본

기존 Full-Car/MF 타이어 모델을 사용하지 않습니다. 첨부 원본 ZIP은 별도로 보존했고, 이 폴더는 실제 실행·감사를 거친 수정 사본입니다. 논문 DOI: 10.1016/j.aei.2022.101764.

## 실행

ZIP을 풀고 matlab 폴더에서 `paper_selftest`를 실행한 다음 `run_requested_40kph`를 실행하세요. 요청한 40 km/h·μ=0.85·0°/3°/7°를 계산합니다. 결과는 results_requested_40kph 폴더에 저장되며 변수는 PAPER_STABILITY3D입니다. MATLAB과 GNU Octave에서 동작하며 이번 클라우드 실행은 GNU Octave 9.4.0을 사용했습니다.

`run_figure6`은 논문에 표시된 중간각 3.5°를 사용합니다. 요청한 3°와 구분하세요. `run_figure2`는 논문에 명시된 80 km/h·0°·μ=0.85 조건용이며, run_original_210_conditions는 선택적 대규모 실행입니다. 이번에는 요청한 세 조건만 실행했습니다.

## 수정한 부분

1. 식(11) 수직하중과 Fy/m의 연립관계를 고정 5회 반복 대신 접촉 상태별 해석해로 계산합니다. 원래 약 65 N 잔차가 생겼던 문제를 수정했습니다. 771개 상태·7개 경계 사례를 검증했고 반올림 잔차는 최대 1.82e-12 N입니다.
2. 기존 PCA는 내부 한계점을 계산하고도 무시했으며, 일부 꼭짓점이 vc=±16.59/r=±0.674까지 나가 원래 시험 격자를 벗어났습니다. 새 방식은 roll 한계점→안쪽 횡속도 한계점→실제 안정점 8개→모든 불안정 격자점 배제 순서를 사용합니다. 안쪽 순위·지원점 순위의 구체값은 논문 미공개 부분의 재구성 가정입니다.
3. RK4 dt=0.01초로 계산하고 dt=0.02초와 비교했습니다. 격자 41×31×31, vc±10·r±0.4·phi±0.4, 5초 시간은 유지했습니다.
4. 조향각별 임의 축소·파라미터 피팅·단조성 강제는 사용하지 않았습니다. 수식·Table 1 값을 확인하고 수치 해법과 경계 추출을 수정했습니다.

## 공개값과 가정

Table 1: m=1300 kg, Izz=2500 kgm², Ixx=700 kgm², L=2.4 m, lf=lr=1.2 m, h=0.54 m, df=dr=0.7 m(반트레드), Kphi=43100 Nm/rad, Cphi=1400 Nm/(rad/s).

미공개 가정: ms=1170 kg, hphi=0.35 m, Burckhardt [1.28,23.99,0.52], Ks=1, lambda_long=0, 초기 p=0, 동적 종방향 속도, 판정 5초. 기본 물리 가정값은 업로드 ZIP과 같습니다. 본문 식(10)의 횡력 부호는 Appendix B/C의 -Ks 복원 부호와 불일치하므로 Appendix B/C와 일관된 -1을 유지했습니다.

저속 u<0.5 m/s는 모델 적용범위 이탈로 별도 집계합니다. 이를 논문의 과도 yaw·미끄러짐·전복 기준 위반과 동일시하지 마세요. reason bit 8은 비유한 수치 상태 또는 저속 가드를 뜻하며 result의 두 별도 count가 원인을 구분합니다. 불안정 원인은 첫 위반까지 기록하고, 안정 궤적은 전체 5초를 계산합니다.

## 확인 결과와 한계

기본 동적 속도 가정의 요청 세 조건은 안정점 수 36,983→36,731→34,405개, 내부 부피 10.56→9.765333→9.013333입니다. 같은 소스에서 속도를 고정하는 대안의 부피는 단조 감소하지 않았습니다. 원래 yaw 격자는 논문 Figure 6 영역 일부를 자르고, 논문의 중간각은 3.5°입니다. 따라서 핵심 감소 경향을 조건부로 확인했지만 정확한 논문 수치·형상의 재현이라고 주장하지 않습니다.

실제 8개 꼭짓점과 내부 불안정 격자점 0개를 검사했습니다. 격자 사이 모든 상태의 안정성·점근 안정성을 보장하지 않습니다. 감사 문서와 수식 대응은 docs에 있습니다.
