# CDC 2차원 초기상태 안전·복귀 영역

첨부 `CDC_shift_stability_full_code.zip`의 Full-Car/MF/CDC 모델을 사용하며, 초기조건 격자를 **횡속도와 요레이트 두 축**으로 계산합니다. 초기 롤각은 모든 점에서 **0 rad**로 고정합니다. 시뮬레이션 중 롤 운동과 롤에 따른 하중이동은 기존 32상태 동역학에 그대로 포함됩니다. 여러 초기 롤각의 3차원 결과를 투영한 자료가 아닙니다.

## 계산 조건

| 항목 | 설정 |
|---|---|
| 속도 | 50, 60, 70, 80, 90, 100 km/h |
| 노면 μ | 0.9, 0.8, 0.7, 0.6, 0.5 |
| 전륜 휠 조향각 | 0, 0.5, 1, 1.5, 2, 2.5, 3° |
| 초기 횡속도 | −10~10 m/s, 간격 0.5, 41개 |
| 초기 요레이트 | −0.4~0.4 rad/s, 간격 0.8/30, 31개 |
| 초기 롤각 | 0 rad 고정 |
| 판정 시점 | 5초와 10초, 한 궤적에서 두 시점 저장 |
| 적분 | RK4, `Ts=0.01 s`, `Nsub=20`, `dt=0.0005 s` |
| 코너별 스프링·CDC 전류 | 30,790 N/m · 950 mA |
| 운동 레버비 | 전륜 0.8613, 후륜 0.7970 |

마모는 `[FL FR RL RR]` 순서의 `[0 0 0 0]`, `[25 25 0 0]`, `[50 50 25 25]`, `[0 0 25 25]`, `[25 25 50 50]`입니다. 210 운전조건 × 마모 5종 × 1,271개 격자점으로 **1,334,550개 초기값 문제**를 계산하며, 선택 영역의 셀 중심 검증이 추가됩니다. 이전의 서스펜션 81모드 정상상태 LUT와 다른 연구입니다.

## 초기화와 영역의 의미

첨부 코드의 기본 `trim` 초기화를 유지합니다. 정상선회점의 수직·비현가 위치 및 하중전달 상태를 기준으로 두고 횡속도·요레이트를 격자 값으로 바꿉니다. **차체 롤각 상태만은 항상 절대값 0**으로 대입합니다. 따라서 모든 숨은 상태가 0인 초기화가 아니며, 지정된 숨은 상태에서의 조건부 2차원 단면입니다. 타이어 슬립과 휠 속도는 각 격자점의 운동학 및 자유회전 종력 조건에 맞춰 설정합니다.

정상선회점 계산이 실패하면 첨부 코드대로 `kinematic_zero` 초기화로 안전 판정만 계산하고, 복귀 판정은 미확정으로 남깁니다. 정상선회점은 전체 내부 잔차, 접지·하중·운용 한계와 내부 29상태 Jacobian의 국소 고유값을 확인한 경우에만 복귀 기준점으로 사용합니다. 전역 yaw 각도와 세계좌표 3개 상태는 정상선회 중에도 변하므로 평형점 잔차에서 제외합니다.

| 저장 마스크 | 의미 |
|---|---|
| `safe` | 지정 시점까지 횡가속도·접지하중·전체/축별 LTR·모델 정의역 검사 통과 |
| `yaw_policy` | 적분된 구간에서 절대 요레이트 정책 위반을 관측하지 않음 |
| `guarded_safe` | `safe & yaw_policy` |
| `recoverable` | `safe`이고 검사된 정상선회점 부근에서 마지막 1초의 상태오차·상태미분 기준 통과 |
| `safe_unresolved` | 제약은 통과했으나 복귀를 확인하지 못한 상태 |
| `stable_mask` | 마지막 10초 시점의 `recoverable & yaw_policy`가 기본 선택 영역 |

마스크의 세 번째 차원은 5초/10초 판정 시점입니다. 롤각 축이 아닙니다. 복귀·제약 판정의 수치 허용값은 공학적 선택이며, 점근안정성이나 연속 영역의 불변성을 증명하지 않습니다. 비선택 점에는 제약 위반과 안전하지만 복귀 미확정인 점이 모두 들어 있습니다.

요레이트 정책은 `0.85*mu*g/U`의 원점 기준 절대 한계로 별도 저장합니다. 논문식 이동 벡터를 더해 영역을 옮기거나 포함관계를 강제하지 않습니다. MF 진폭의 `mu/0.9` 배율 및 CDC 데이터는 첨부 모델과 같습니다.

## 2차원 셀과 MAT 구조

MAT 변수명은 **`STABILITY2D`**입니다. `CASE(1:5)`가 마모 5종이고, 각 마모의 `grid.vc`, `grid.r`, `masks`, `stable_mask`, `trim`, `summary`를 저장합니다. `stable_points`와 `nonselected_points`는 `[vc0, r0]`의 두 열입니다.

선택된 격자 셀은 **네 꼭짓점**이 통과한 경우에만 후보가 됩니다. 기본적으로 셀 중심점을 추가 시뮬레이션하여 통과한 셀만 저장합니다. `region.sampled_area`는 통과한 셀의 면적 합이며 단위는 `(m/s)*(rad/s)`입니다. 3차원 부피나 인증된 흡인영역 면적으로 해석하지 않습니다. 원시 표본 마스크를 볼록껍질로 대체하지 않습니다.

## 실행

MATLAB/Octave에서 `matlab` 폴더를 경로에 추가한 뒤 실행합니다.

```matlab
addpath('matlab');
run_shift_study_2d('selftest');
R = run_shift_study_2d('full');
```

기본 M-code 경로는 별도 타이어·댐퍼 데이터 파일이나 최적화 툴박스 없이 실행합니다. 클라우드 계산은 같은 식과 판정에 대해 원본 M-code와 비교 검증한 C++ 가속 경로를 사용할 수 있습니다. 가속 경로에서도 매 적분 노드 `dt=0.0005 s`에서 제약을 검사하고, 상태를 클리핑하여 되돌리지 않습니다. 5초와 10초 판정은 같은 궤적에서 얻습니다. 초기 롤각을 다시 축으로 추가하거나 좌표를 평행이동하는 작업은 하지 않습니다.

준비된 C++ 실행 파일을 사용한 전체 계산 실행기는 다음과 같습니다.

```bash
g++ -O3 -std=c++17 -fopenmp \
  cdc_shift_2d/native/cdc2d_native.cpp \
  -o cdc_shift_2d/native/cdc2d_native
python cdc_shift_2d/run_full_210.py \
  --native cdc_shift_2d/native/cdc2d_native \
  --output results/cdc_shift_2d_phi0
```

`--octave` 옵션으로 사용할 Octave 실행 파일을 지정할 수 있습니다. 계산 상태는 결과 폴더의 `progress.json`에 기록합니다. 한 조건의 마모 5종이 모두 끝나면 210조건 중 하나를 완료한 것으로 집계합니다.

완료 조건과 마모별 체크포인트는 코드·설정·격자·엔진 서명이 같을 때만 이어서 사용할 수 있습니다. 기존 3차원 `STABILITY3D` MAT나 이전 81모드 LUT를 이 결과 캐시와 혼합하지 마세요.

## 그림과 비교

Python의 NumPy, SciPy, Matplotlib을 사용합니다.

```bash
python cdc_shift_2d/plot_results.py \
  --input results/cdc_shift_2d_phi0 \
  --output results/cdc_shift_2d_phi0/figures --overview
```

계산 중 완료된 MAT를 순차적으로 그리려면 `--watch`를 추가합니다. 파일명은 `cdc2d_*.mat`이며 마모 체크포인트는 그림 목록에서 제외합니다. `--overview-kind recoverable`로 절대 요레이트 정책을 제외한 복귀 마스크의 비교 그림도 만들 수 있습니다. 이 옵션은 저장된 자료의 표시만 바꾸며 시뮬레이션 판정을 수정하지 않습니다.

`--watch`는 `progress.json`의 계산 완료 상태와 전체 조건의 그림 생성을 확인하면 종료합니다. 계산이 실패하거나 취소된 상태면 완료된 그림을 보존하고 오류 상태로 종료합니다. 진행 파일이 없는 폴더에서는 사용자가 중단할 때까지 새 MAT를 기다립니다.

각 조건의 PNG는 마모 5종을 나란히 보여 줍니다. 첫 행은 전체 격자, 둘째 행은 모든 마모에 공통된 **절대좌표 확대 구간**입니다. 확대는 눈금을 좁히는 표시이며 좌표를 재중심화하지 않습니다.

- 흰색: 제약 또는 모델 정의역 위반
- 회색: 안전 판정 통과, 복귀 미확정
- 파란색: 복귀했으나 절대 요레이트 정책 초과
- 초록색: 복귀 및 요레이트 정책을 함께 통과한 선택 표본
- 주황 점선: 5초 선택 마스크 경계
- 진초록 실선: 10초 선택 마스크 경계
- ×: 실제 계산한 정상선회점, 복귀 기준으로 사용할 수 없는 점은 빨간색

경계선은 원시 격자 마스크 사이의 시각적 보간입니다. 격자 밖에 불안정 값을 덧붙여 닫힌 경계를 만들지 않습니다. 표본이 격자 경계에 닿으면 `grid-truncated`를 표시합니다. 선택 집합이 비어 있으면 빈 집합 그대로 표시하며 다른 마모나 다른 조향각의 영역을 대신 그리지 않습니다.

`--overview`는 같은 속도·μ에서 조향각별 10초 선택 경계를 공통 좌표에 겹칩니다. 전체 계산에서는 6속도 × 5마찰의 **30개 비교 그림**입니다. 서로 다른 조향각의 복귀 집합에 인위적인 포함관계나 단순 평행이동을 요구하지 않습니다. 5초/10초 안전 집합은 시간 증가에 따라 줄어들 수 있지만, 복귀 판정은 대기시간 증가로 더 많은 점이 통과할 수 있습니다.
