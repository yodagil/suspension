# MF210 transient hybrid — 40 km/h, μ=0.85

`run_mf210_hybrid.m`은 계산 함수와 설정을 포함한 **단일 MATLAB 파일**입니다.

```matlab
run_mf210_hybrid                 % 기본: results_matlab 폴더에 새로 계산
run_mf210_hybrid('my_results')   % 출력 폴더 지정
plot_mf210_hybrid('results')     % 동봉된 계산 결과 다시 표시
```

각 조향각 0°, 3.5°, 7°에서 동일한 81×55×31=138,105개 초기 상태를 독립 계산합니다. 격자는 `vc=-10:0.25:10 m/s`, `r=(-27:27)×0.8/30 rad/s`, `phi=(-15:15)×0.8/30 rad`입니다. 계산 시간이 길 수 있습니다. MATLAB R2016b 이상이 필요하며 외부 도구상자는 사용하지 않습니다.

차체는 논문의 운동/롤 방정식, 타이어는 기존 210 코드의 정상 타이어 MF 계수·힘 오프셋·마찰 타원과 슬립 완화/자유 회전 휠을 사용한 **18상태 혼합 모델**입니다. 논문 Burckhardt 모델의 정확 재현이나 기존 full-car 차체 전체 모델은 아닙니다. MF는 원본과 같이 `μ/0.9`를 곱하며 최대 힘을 `μFz`에 다시 맞추지 않습니다. `ms=1300 kg`, `hphi=0.54 m`는 명시적 폐쇄 가정입니다. Eq.11 하중은 기존 210 코드의 0.03초 `ay_load` 필터로 계산합니다.

초기 상태는 `[u,vc,r,phi,p,kappa(4),alpha(4),omega(4),ay_load]` 순서입니다. `u=40/3.6`, `p=0`, `kappa=0`, `alpha=-delta`(뒤 타이어는 0), `omega=u*cos(delta)/Rw`, `ay_load=0`을 유지합니다. 따라서 초기 슬립은 각 격자점 속도에서 평형으로 다시 설정하지 않습니다. 속도는 40 km/h로 고정합니다.

5초 동안 0.01초 간격으로 `|r| <= 0.85*μ*g/u`, `|ay| <= μ*g`, 모든 원시 휠 하중 `Fz>0`을 검사합니다. 적분은 관측 간격당 RK4 20회(0.0005초)이며 비유한 값/속도 정의역 오류도 실패로 저장합니다. 이 결과는 지정 초기화와 유한 시간·표본 격자의 판정입니다.

각 각도마다 `classification_*deg.mat`의 `PAPER_STABILITY3D`에 설정·메타데이터·Stable/Unstable 표본을, `region210_*deg.mat`의 `REGION210`에 원본 210 코드로 추출한 영역을 저장합니다. 내부 영역의 유효성은 **격자에 있는 불안정 표본이 내부/경계에 0개**임을 뜻하며 연속 공간 전체의 안정성을 보장하지 않습니다. 원본 영역 함수는 8개 점의 볼록껍질을 사용하므로 항상 정확한 육면체/6면이 되는 것은 아닙니다.

두 구조체를 함께 넣은 `stable_point_40kph_0.85mu_{0,3.5,7}deg.mat`도 저장합니다. 공개된 결과 폴더에는 이 통합 파일 3개가 있으며 `plot_mf210_hybrid`로 표시할 수 있습니다.

영역 선택은 각도별로 독립 수행하며 중첩을 강제하는 교집합, 스케일 조정, 잘라내기를 사용하지 않습니다. 그림은 실제 저장 좌표와 동일한 축·직교 카메라를 사용합니다. MATLAB/다른 렌더러 사이의 투명도 표시는 다를 수 있습니다.

`source/`에는 계산에 사용한 함수 사본, `provenance/`에는 원본 MF/영역 추출 출처 및 수치 일치 검증, `delivery_manifest.json`에는 파일별 SHA-256이 있습니다. 개인 논문 PDF와 원본 업로드 ZIP은 포함하지 않습니다. 동봉 결과의 엔진과 재계산 엔진은 각 MAT 메타데이터에 구분해 기록됩니다. 이 환경에서는 MATLAB 실행 검증이 불가능하여 MATLAB 호환 M-code를 Octave로 소규모 실행 확인했습니다.

전체 정밀 격자의 실행 엔진은 M-code와 수치 일치를 검증한 C++이며 실제 엔진 소스도 `source/native_mf.cpp`에 포함했습니다. Linux에서는 `g++ -O3 -std=c++17 -ffp-contract=off -fopenmp source/native_mf.cpp -o native_mf`로 빌드할 수 있습니다. 입력 텍스트의 각 행은 `[vc r phi]`이고, 예를 들어 `./native_mf points 40 .85 3.5 initial_points.txt output.csv .01 5 2`로 계산합니다. 단일 `.m` 파일 자체에는 C++ 컴파일이 필요하지 않습니다.
