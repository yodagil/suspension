# MATLAB 코드 · 초기값 변경 전 v3 방식

현재 210개 계산은 초기값 변경 전 기준 방식으로 재개했습니다. 초기 완화 횡슬립은 `x(21:24)=-delta_w`, 초기 휠 회전속도는 `max(ux*cos(delta_w),0)/Rw`이며, 초기 종방향 완화 슬립은 0입니다. 초기 횡속도·요레이트로 슬립각을 맞추는 변경과 새 격자 박스 영역 fallback은 적용하지 않습니다.

파일 하나로 실행하려면 [stability_sweep_210.m](stability_sweep_210.m)을 저장한 뒤 MATLAB에서 `stability_sweep_210`을 실행하세요. 모델·적분·원래 영역 추출·저장 함수가 모두 포함돼 다른 코드나 C++ 실행 파일이 필요하지 않습니다. 결과는 파일 옆 `results_single_mfile_reference09_direct_start`에 저장합니다. 파일 해시 계산에는 MATLAB Java VM을 사용합니다.

속도 50·60·70·80·90·100 km/h, μ 0.9·0.8·0.7·0.6·0.5, 앞 휠 조향각 0·0.5·1·1.5·2·2.5·3°의 210조건, 마모 5종, 각 39,401개 초기조건(41×31×31), 5초, Ts=0.01초, RK4 하위 적분 20회를 유지합니다. 파일명은 `stable_point_80kph_0.9mu_2deg.mat` 형식입니다. 일부 조건만 실행하려면 `stability_sweep_210(struct('speeds',80,'mus',0.9,'steers',2))`를 사용하세요.

ZIP 안의 여러 함수 파일 방식은 `run_210_conditions.m`을 실행하며 `results_mcode_reference09_direct_start`에 저장합니다. MATLAB 직접 실행은 현재 클라우드의 동일 방정식 C++ 가속 경로보다 느립니다. C++ 소스와 빌드 스크립트도 포함했습니다. 배포 runner는 MATLAB 경로의 누적 원인 코드 설명 문자열만 실제 5초 설정에 맞게 바로잡았으며 수치 계산은 바꾸지 않았습니다.

노면 μ는 기준 0.9에 대한 배율 `mu/0.9`로 종·횡 타이어 Magic Formula 진폭에 반영합니다. 요율 한계는 `0.85*mu*g/ux`, 횡가속도 한계는 `mu*g`입니다. μ=0.9의 80 km/h·2° 기준 MAT와 마모 5종의 판정·좌표·영역을 재현했던 v3 모델입니다. 유효한 내부 영역을 얻지 못한 조건은 원래 방식대로 NaN으로 기록하며, 안정·불안정 좌표는 보존합니다.

이후 시험했던 운동학적 초기화 및 격자 박스 후처리 결과는 별도의 실험 결과이며 현재 210조건 계산에 섞지 않습니다. 이전 실험 코드는 Git 이력 `2c111a4`에 남아 있습니다. `plot_stability_mat.m`은 저장된 MAT를 보는 선택 도구이며, 경고문에 숫자 스칼라를 전달하도록 고친 출력 오류 수정은 유지했습니다. 기존 실험·클라우드 MAT를 새 단일 파일의 캐시로 혼용하면 코드 해시 검증이 거부할 수 있습니다.
