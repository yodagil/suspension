# V2 Full-car CDC 2차원 안전·복귀 영역

이 계산은 사용자가 올린 `CDC_2D_stability_v2_full.zip`의 **`stability_fullcar_2d_v2.m`**을 사용합니다. 차량의 32상태, 롤 운동, 수직 현가·비현가 운동, 타이어 완화, 휠 회전, 하중이동 및 전·후륜 CDC 댐퍼를 유지합니다. 그래프의 초기조건 축만 횡속도와 요레이트입니다.

같은 ZIP의 `stability_shift_2d_v2.m` 및 `run_shift_study_2d_v2.m`은 별도의 평면 축약 모델입니다. 여기의 210조건 생산 계산에는 사용하지 않습니다.

마모 순서는 `[FL FR RL RR]`입니다.

```matlab
[ 0  0  0  0;
 25 25  0  0;
 50 50 25 25;
  0  0 25 25;
 25 25 50 50]
```

## V2의 초기 롤각과 선택 영역

기본값은 **`slice_mode='trim'`**입니다. 각 운전조건·마모의 정상선회점에서 롤각을 포함한 숨은 상태를 가져오고, 초기 횡속도·요레이트 두 값만 격자에 따라 바꿉니다. 따라서 초기 롤각은 모든 조합에서 0이 아니라 **해당 조합의 `phi_eq`**입니다. 각 마모의 실제 초기 롤각은 `CASE(i).fixed_initial_roll_rad`에 기록됩니다. 타이어 슬립과 휠 속도는 바뀐 초기 횡속도·요레이트에 맞추어 초기화합니다.

이는 하나의 조건부 초기상태 단면입니다. 롤각을 세 번째 격자 축으로 스윕하거나 롤 동역학을 제거하지 않으며, 이전 `phi(0)=0` 결과를 투영·평행이동하여 만든 자료도 아닙니다. 정상선회점 탐색에 실패하면 코드가 명시적으로 초기화 대안을 기록하고 복귀 여부를 미확정으로 남깁니다.

V2 기본 대표 영역은 **`recoverable`**입니다. 절대 요레이트 정책의 영향은 별도 **`guarded_recoverable`**에 남깁니다. `recoverable`도 여전히 횡가속도·접지·LTR·모델 범위의 경로 제약을 통과하고, 검사된 정상선회점 근처로 마지막 1초 동안 수치적으로 복귀한 초기점입니다.

| 마스크 | 의미 |
|---|---|
| `safe` | 해당 시점까지 물리·모델 범위 제약 통과 |
| `yaw_policy` | 관측 구간에서 절대 요레이트 정책 위반을 보지 않음 |
| `guarded_safe` | `safe & yaw_policy` |
| `recoverable` | `safe`이면서 정상선회점 복귀 판정 통과 |
| `guarded_recoverable` | `recoverable & yaw_policy` |
| `safe_unresolved` | 제약은 통과했지만 복귀 미확인 |
| `stable_mask` | 기본 설정에서 마지막 시점의 `recoverable` |

절대 요레이트 정책은 `0.85*mu*g/U`이며 경계를 임의로 옮기지 않습니다. MF 타이어 힘의 μ 배율은 원래의 `mu/0.9`입니다. 이는 각 하중·마모에서 힘의 피크가 정확히 `mu*Fz`가 되도록 새로 보정한 모델이라는 뜻은 아닙니다.

제약은 매 `dt=0.0005 s` 적분 노드에서 검사하며, 상태를 한계 안으로 사후 투영하여 통과시키지 않습니다. `safe_unresolved`와 비선택 초기점을 모두 발산이나 불안정으로 확정해서 해석하면 안 됩니다. 유한시간·표본 판정이며 전역 흡인영역 또는 인증된 불변집합의 증명이 아닙니다.

## 결과 조회

새 결과 위치는 `results/fullcar_2d_v2/`입니다. 기존 결과 폴더와 캐시를 혼용하지 않습니다. 시나리오별 MAT 변수명은 **`STABILITY2D`**입니다.

```matlab
D = load('fullcar2d_v2_80kph_mu0.9_delta+2_trim_trim.mat');
S = D.STABILITY2D;
C = S.CASE(1);  % 정상 타이어
phi_initial = C.fixed_initial_roll_rad;
recovered_10s = C.masks.recoverable(:,:,2);
guarded_10s = C.masks.guarded_recoverable(:,:,2);
area_10s = C.region.sampled_area;
```

마스크 배열은 `[49,81,2]`이며 세 번째 축은 5초·10초입니다. `stable_points`는 최종 선택된 **초기 `[vc0,r0]` 좌표**입니다. `region.cell_mask`는 네 꼭짓점과 요청된 중심점 검사를 통과한 2D 셀의 집합이고, `sampled_area`는 그 면적의 합입니다. 연속 영역 전체가 안전하다는 인증 면적으로 해석하지 않습니다. 격자 경계 접촉 플래그가 있으면 전체 영역이 계산 범위 밖으로 이어질 수 있습니다.

## MATLAB 실행

`matlab` 폴더를 MATLAB Current Folder로 두고 먼저 자체 검사를 실행합니다.

```matlab
run_fullcar_2d_v2('selftest');
R = run_fullcar_2d_v2('pilot'); % 80 km/h, mu=.9, -2/0/+2 deg, 정상 타이어
R = run_fullcar_2d_v2('wear');  % 같은 조건, 마모 5종
R = run_fullcar_2d_v2('full');  % 210조건 × 마모 5종
```

기본 MATLAB 엔진은 추가 C++ 실행 파일 없이 같은 방정식을 직접 적분합니다. SHA-256 출처 검사에는 MATLAB 기본 Java VM을 사용합니다. 클라우드 대규모 계산은 원본 M-code와 검증한 native 가속 경로를 사용하며, MATLAB 직접 실행은 더 느릴 수 있습니다. 전체 재실행과 native 빌드 명령은 생산 실행기 `run_full_210.py`의 옵션 및 `native` 폴더 설명을 함께 확인하십시오.

## 그림

```bash
python fullcar_2d_v2/plot_results.py \
  --input results/fullcar_2d_v2 \
  --output results/fullcar_2d_v2/figures --overview --watch
```

각 조건의 그림은 마모 5종을 비교합니다. 초록색은 복귀 표본, 회색은 제약 통과·복귀 미확정, 흰색은 제약/모델 범위 위반입니다. 주황 점선은 5초 선택 경계, 진한 초록 실선은 10초 선택 경계, 보라 점선은 절대 요레이트 정책까지 통과한 복귀 경계입니다. 각 마모 패널에 실제 초기 롤각을 표시합니다.

조향각 비교 그림 30개는 같은 속도·μ에서 7개 조향각을 동일한 절대 좌표로 겹칩니다. 서로 다른 조향각에서 `phi_eq`는 달라지므로 각 조향각의 일관된 trim 단면을 비교하는 것입니다. 모든 그림은 저장된 원시 마스크를 표시하며 외부를 0으로 채워 경계를 강제로 닫거나, 볼록껍질로 구멍을 메우거나, 경계를 평행이동하지 않습니다. 등고선 보간은 시각화이며 새 시뮬레이션 표본을 생성하지 않습니다.
