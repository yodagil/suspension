실험 조건: 속도 50·60·70·80·90·100 km/h, 노면 마찰계수 0.9·0.8·0.7·0.6·0.5, 앞 휠 조향각 0·0.5·1·1.5·2·2.5·3°. 바퀴 조향각은 [angle, angle, 0, 0]입니다.
