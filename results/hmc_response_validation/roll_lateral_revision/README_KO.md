# 롤·요레이트·횡속도 정합성 개선 검증

받은 CarSim 72채널 MAT와 `CarSim_Native_Outputs.zip`의 346채널 BIN/ERD를 이용해 원인을 분리하고 수정 독립 모델을 다시 실행했습니다. 조건별 10초·10,001개 샘플의 절대 응답을 비교했습니다. 타이어·현가 계수 조정, 곡선 이동, 시간 정렬, 출력 배율 보정은 하지 않았습니다.

두 조건 모두 정상 타이어, 정상 스프링, 네 바퀴 CDC 950 mA이며 물리 초기조건은 횡속도 +0.1 m/s·차체 요레이트 +0.35 rad/s입니다. 차체·현가·휠 회전 상태는 각 모델이 계산한 정상상태에서 시작합니다. 70 km/h에서는 조향 명령 2.5°, CarSim 실제 전륜 평균각 약 2.222165°를 구분했습니다.

| 조건 | 횡속도 RMSE (m/s) | 요레이트 RMSE (rad/s) | 롤 RMSE (°) | 피치 RMSE (°) |
| --- | ---: | ---: | ---: | ---: |
| 50 km/h · μ=0.5 · 0° | 0.002935 | 0.000737 | 0.007229 | 0.000691 |
| 70 km/h · μ=0.6 · 2.5° | 0.009638 | 0.002434 | 0.010599 | 0.003999 |

| 조건 | 롤 최대값 CarSim / 모델 (°) | 10초 롤각 CarSim / 모델 (°) | 10초 요레이트 CarSim / 모델 (rad/s) |
| --- | ---: | ---: | ---: |
| 50 km/h | 0.671046 / 0.715421 | 0.001966 / 0.001951 | -0.000146 / -0.000144 |
| 70 km/h | 2.467510 / 2.484586 | 2.017953 / 2.011899 | 0.198620 / 0.200903 |

주요 변경과 근거:

- 타이어 완화 상태 재시작: 70 km/h BIN의 초기 Fx/Fy가 내부 슬립비·슬립각 완화 상태를 0으로 둔 MF 계산과 각각 약 0.003 N·0.055 N 이내로 일치했습니다. 이에 맞춰 내부 완화 상태를 초기화했습니다. 초기 차량 운동으로 생기는 **기하학적 슬립각**은 계속 바퀴 운동학으로 계산합니다. 이 기하학적 값과 힘 지연을 나타내는 내부 완화 상태는 다릅니다.
- 롤 모멘트 평형: 비현가질량의 횡방향 관성 반력, 롤에 따라 회전하는 현가 하중 작용점, 접촉점 위치와 타이어 Mx를 추가했습니다. Mx 식을 측정 Fy와 원본 계수로 재평가하면 BIN의 Mx와 RMS 약 2.25×10⁻⁶ N·m로 일치했습니다. 이것은 개별 타이어 식 검증이며 전체 차량의 정확한 재현을 뜻하지는 않습니다.
- 바퀴 속도: 차체 롤·피치 회전과 측정 현가 경로의 속도를 반영해 슬립 목표값을 계산합니다.
- 컴플라이언스·조향: 접촉 하중을 차체 좌표로 바꾸고 원본 caster/KPI 축에 따른 조향 캠버를 반영했습니다. CarSim의 비공개 캐리어/벨트 모델을 완전히 복제한 것은 아닙니다.
- 앞선 Euler 각도 운동학, CDC 1 ms 샘플·2 ms 지연, MF6.2 수직하중 및 구름저항 피치 모멘트를 유지했습니다.

70 km/h의 최신 교체 MAT를 사용했으므로 첫 trim 행은 없습니다. 기록된 0~10초 모든 행을 그대로 사용했습니다. 이전 모델 대비 오차 변화는 `rmse_improvement.json`, 적분·구현 검증은 `numerical_verification.json`에 있습니다. 16개 상태의 M-code/C++ RHS, 2개 초기조건의 독립 M-code 5 ms RK4, Native 10초 적분 간격 1→0.5 ms 비교를 통과했습니다. 전체 10초 M-code 적분을 직접 실행한 것은 아닙니다.

50 km/h에서는 롤 최대값이 약 6.6% 높고, 70 km/h에서도 요레이트·횡속도의 정상상태 차이가 남습니다. 전체 210조건과 타이어 마모 5종의 CarSim 일치를 검증한 결과는 아닙니다. **210조건 계산은 중단 상태를 유지합니다.** 기존 2조건 안정영역 MAT는 수정 전 모델의 참고 결과입니다.

MAT의 `ResponseComparison`에는 선택한 6개 응답, 스프링/댐퍼 힘, 조건·오차 지표·해시만 저장했습니다. 입력 차량·타이어 데이터, 모델 Q/T/c 및 전체 72/346채널 원본은 포함하지 않았습니다. 힘은 `[FL FR RL RR]` 순서의 4×N 배열이며 단위는 N입니다.

```matlab
S = load('comparison_70kph_0.6mu_2.5deg.mat');
R = S.ResponseComparison;
plot(R.time_s,R.carsim_response.roll_deg, ...
     R.time_s,R.independent_response.roll_deg,'--');
legend('CarSim','Revised independent model'); grid on;
xlabel('Time [s]'); ylabel('Roll angle [deg]');
```
