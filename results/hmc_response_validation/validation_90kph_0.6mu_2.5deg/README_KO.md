# 90 km/h 조건 추가 검증

조건: **90 km/h · μ=0.6 · 전륜 조향 명령 2.5° · 정상 타이어 · 정상 스프링 · CDC 950 mA**입니다. 초기 횡속도 +0.1 m/s·차체 요레이트 +0.35 rad/s, 재시작 후 10초를 비교했습니다. CarSim 기록은 0~12초 트림 후 12~22초 재시작 구간입니다. 독립 모델은 기존 방식대로 수치적으로 구한 정상선회점을 초기상태로 사용했으며, 별도의 12초 트림 시간적분은 실행하지 않았습니다. 조향휠 비율은 14.805입니다.

50/70 km/h 비교에 사용한 수정 모델의 소스·실행파일·입력 해시 19개가 동결 목록과 동일합니다. 이 90 km/h 자료에 맞춰 모델이나 계수를 수정하지 않았습니다. 독립 모델의 정상선회점부터 계산했으며 CarSim 정상상태 값을 주입하지 않았습니다. 차체·현가·휠 회전 상태는 자체 정상상태를 유지하고, 타이어 내부 완화 상태는 이전 검증에서 정한 대로 0으로 재시작했습니다.

CarSim 정상상태의 실제 전륜 평균 조향각은 **2.17661686°**입니다. 이는 명령각 2.5°와 다르며 실행 중 컴플라이언스 등으로 변합니다. 첫 두 출력 행은 동일하고, 첫 기록 횡속도는 0.0982826317 m/s·요레이트는 0.35 rad/s입니다. 첫 롤각·피치각은 자체 트림 값이며 0으로 초기화하지 않았습니다. 재시작 후 0~10초 **10,001개 전체 샘플**의 절대값을 사용했고 시간 이동·행 삭제·진폭 보정은 적용하지 않았습니다.

| --- | ---: | ---: | ---: |

MAT의 `ResponseComparison`은 선택한 6개 응답, 네 코너 스프링·댐퍼 힘, 조건·오차 지표·해시만 포함합니다. 힘 배열은 `[FL FR RL RR]` 순서의 4×N, 단위 N입니다. 원본 차량·타이어 입력과 전체 72채널 기록, 내부 Q/T/c 구조체는 포함하지 않았습니다.

한 조건의 시간 응답 검증이며 전체 안정영역이나 210조건의 CarSim 동등성을 확인한 결과는 아닙니다. 기존 210조건 계산은 중단 상태입니다.

```matlab
S = load('comparison_90kph_0.6mu_2.5deg.mat');
R = S.ResponseComparison;
plot(R.time_s,R.carsim_response.roll_deg, ...
     R.time_s,R.independent_response.roll_deg,'--');
legend('CarSim','Unchanged revised model'); grid on;
xlabel('Time [s]'); ylabel('Roll angle [deg]');
```
