# CarSim 시간 응답 비교 결과

수정 독립 모델과 CarSim의 10초 응답을 절대값으로 비교했습니다. 곡선 이동·시간 정렬·배율 보정은 적용하지 않았습니다.

두 조건 모두 정상 타이어, 정상 스프링, CDC 950 mA입니다. 초기 횡속도 0.1 m/s와 차체 요레이트 0.35 rad/s만 변경했고, 롤각·피치각과 나머지 내부 상태는 각 모델의 자체 정상상태 값을 유지했습니다.

이번 실험 모델에는 Euler 각도 운동학·회전 관성 결합, 현가 기구학에 따른 jacking, 타이어 구름 저항의 피치 모멘트, CDC 2 ms 지연, 원본 SPLINE 표의 자연 3차 보간, MF6.2 비선형 수직하중과 경사에 따른 하중 반경을 반영했습니다. CarSim 내부 보간의 끝점 처리와 완전히 같다는 뜻은 아닙니다. 70 km/h 자료를 받은 뒤 원본 타이어 계수와 50 km/h 타이어 출력 검사를 근거로 식을 수정했으므로, 70 km/h 결과를 사전에 보지 않은 맹검 검증은 아닙니다.

| 속도·μ·명령 조향각 | 롤 최대값 CarSim / 독립 모델 (°) | 롤 RMSE (°) | 피치 RMSE (°) |
| --- | ---: | ---: | ---: |
| 50 km/h · 0.5 · 0° | 0.671046 / 0.647436 | 0.015053 | 0.002280 |
| 70 km/h · 0.6 · 2.5° | 2.467510 / 2.124729 | 0.211294 | 0.005058 |

70 km/h 조건의 명령 조향각은 2.5°이며, CarSim trim의 실제 전륜 평균 조향각은 2.222165°입니다. 해당 기록의 첫 행에는 직전 trim 출력이 남아 있습니다. 1 ms부터 요레이트 0.35 rad/s가 반영되며 1·2 ms 출력은 동일합니다. 주 지표는 이 첫 행을 포함한 전체 10,001개 샘플로 계산했고, JSON·MAT의 `diagnostic_metrics_t_gt_0`에는 첫 행만 제외한 진단값을 별도로 넣었습니다.

MAT의 `ResponseComparison`에는 시간, 선택한 6개 응답(횡속도·요레이트·롤각·피치각·종방향 속도·차체 피치 각속도), 네 코너 스프링·댐퍼 힘, 오차 지표, 조건과 해시만 포함됩니다. 힘 배열은 `[FL FR RL RR]`의 4×N이며 단위는 N입니다. 원본 차량·타이어 데이터, 입력 구조체, 전체 72채널 CarSim 기록은 포함하지 않았습니다.

각 PNG는 10초 응답을 표시하며, JSON에는 전체 수치 지표가 있습니다. 한 초기조건의 응답 검증으로 전체 안정영역의 일치까지 확인한 것은 아닙니다. 차이가 남아 있으므로 정확한 CarSim 재현으로 해석하면 안 됩니다.

210조건 계산은 응답 개선을 위해 중단한 상태입니다. 앞서 완료된 2조건은 이전 모델의 참고 결과입니다.

적분 간격 1 ms와 0.5 ms의 10초 응답 비교에서 두 조건의 롤각 차이는 최대 3.74×10⁻⁸°, 피치각 차이는 최대 3.90×10⁻⁹°였습니다. 현재 CarSim과의 차이는 적분 간격을 줄여도 해소되지 않았습니다. `numerical_verification.json`은 이 수치 수렴 검사와 짧은 M-code/Native 적분 일치 검사를 담고 있습니다.

MATLAB에서 비교 응답을 확인하는 예:

```matlab
S = load('comparison_70kph_0.6mu_2.5deg.mat');
R = S.ResponseComparison;
plot(R.time_s, R.carsim_response.roll_deg, ...
     R.time_s, R.independent_response.roll_deg, '--');
xlabel('Time [s]'); ylabel('Roll angle [deg]');
legend('CarSim', 'Independent model'); grid on;
```
