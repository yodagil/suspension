# 50·70·90 km/h 과도응답 및 차체 각속도 비교

[단일 MATLAB 시뮬레이션 코드·ZIP·실행 설명](../../../hmc_standalone/response_v3/README_KO.md)

세 조건을 같은 일반 모델과 동일한 옵션으로 다시 계산하고, 차체 롤레이트·피치레이트를 추가했습니다. 이전 자료를 이용한 모델 개선 후 재평가이므로 맹검 검증은 아닙니다. 시간 이동·행 삭제·출력 배율 조정이나 조건별 입력 계수 보정은 적용하지 않았습니다.

50 km/h는 μ=0.5·조향 명령 0°, 70/90 km/h는 μ=0.6·조향 명령 2.5°입니다. 모두 정상 타이어·정상 스프링·CDC 950 mA, 물리 초기 횡속도 +0.1 m/s·요레이트 +0.35 rad/s입니다. CarSim은 트림 12초 후 재시작 10초 기록이며, 독립 모델은 수치적으로 구한 자체 정상선회점을 초기 상태로 사용했습니다. 별도 12초 모델 트림 시간적분은 하지 않았습니다.

**각속도는 CarSim과 같은 차체 좌표계 p/q입니다.** CarSim MATLAB 열 12/13(deg/s), 모델 상태 11/12(rad/s)를 단위 변환했습니다. Euler 롤·피치각을 수치 미분한 값과 다릅니다. 정상 선회에서 피치각이 일정해도 차체 피치레이트 q는 0이 아닐 수 있습니다.

이전 공개 모델 대비 오차 변화는 각 MAT/JSON의 `rmse_change_from_previous_model`에 저장했습니다. `reduction_percent`가 음수이면 오차 증가입니다. 아래 증가는 감소한 지표와 함께 그대로 표시했습니다.

- 50 km/h 횡속도: 0.002890294 → 0.003126022 m/s (8.16% 증가)
- 50 km/h 롤각: 0.007219587 → 0.008270501 deg (14.56% 증가)
- 50 km/h 차체 롤레이트: 0.09591206 → 0.1107343 deg/s (15.45% 증가)
- 50 km/h 횡가속도: 0.02508397 → 0.02944853 m/s^2 (17.40% 증가)
- 70 km/h 롤각: 0.01019936 → 0.01574881 deg (54.41% 증가)
- 70 km/h 피치각: 0.003685287 → 0.003821694 deg (3.70% 증가)
- 90 km/h 피치각: 0.00741232 → 0.008232672 deg (11.07% 증가)

활성 모델 옵션은 MAT/JSON의 `model_options`에 저장했고 세 조건에서 동일함을 확인했습니다.

타이어 내부 완화 상태를 구조 변형 상태로 다루는 항을 적용했습니다. 물리적인 기하학적 슬립각과 내부 힘 지연 상태는 구분하며, 재시작 내부 상태는 기존에 검증한 대로 0입니다.

차체 CG 기준의 비현가질량 관성 결합을 횡방향·롤·요 운동에 반영했습니다. 피치 등 나머지 운동에는 기존 방정식이 유지되므로 완전한 다물체 관성 결합 모델은 아닙니다. 입력 질량·관성·타이어 계수는 변경하지 않았습니다.

입력 계수 파일 해시가 이전 모델과 동일한지 확인했습니다. 수치 구현·적분 검증은 [검증 JSON](numerical_verification.json)에 있으며, 이는 CarSim 전체 모델과의 동등성을 뜻하지 않습니다. 한 초기조건의 세 속도 응답 비교로 전체 안정영역이나 마모 5종·210조건의 일치를 검증한 것은 아닙니다. 기존 210조건 계산은 중단 상태입니다.

- 90 km/h: [8개 응답 그림](comparison_90kph_0.6mu_2.5deg.png) · [비교 MAT](comparison_90kph_0.6mu_2.5deg.mat)

MAT의 `ResponseComparison`에는 시간, 선택한 8개 응답, 네 코너 스프링·댐퍼 힘, 조건·오차 지표·해시만 포함됩니다. 힘은 `[FL FR RL RR]` 순서의 4×N이며 단위는 N입니다. 원본 전체 72/346채널, 차량·타이어 입력 계수, 내부 Q/T/c/D 및 로컬 경로는 포함하지 않았습니다.

```matlab
S = load('comparison_90kph_0.6mu_2.5deg.mat');
R = S.ResponseComparison;
plot(R.time_s,R.carsim_response.rollrate_degps, ...
     R.time_s,R.independent_response.rollrate_degps,'--');
legend('CarSim','Revised model'); grid on;
xlabel('Time [s]'); ylabel('Body roll rate [deg/s]');
```
