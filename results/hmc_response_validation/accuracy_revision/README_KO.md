# 50·70·90 km/h 추가 정합성 비교

기존 입력 계수는 유지하면서 타이어 완화·좌표계·속도 제어/구동 토크 계산을 보완하고 세 조건을 모두 다시 실행했습니다. 이미 확인한 자료를 이용해 일반 모델을 개선한 뒤 재평가한 것이므로 맹검 검증은 아닙니다. 곡선 이동·시간 정렬·출력 배율 조정·조건별 입력 계수 보정은 적용하지 않았습니다.

조건은 50 km/h·μ0.5·조향 명령 0°, 70/90 km/h·μ0.6·조향 명령 2.5°입니다. 모두 정상 타이어, 정상 스프링, CDC 950 mA, 초기 횡속도 +0.1 m/s·차체 요레이트 +0.35 rad/s입니다. CarSim 기록은 12초 트림 후 재시작한 10초 구간이며, 독립 모델은 수치적으로 구한 자체 정상선회점의 차체·현가·휠 회전 상태에서 시작했습니다. 별도 12초 트림 시간적분을 한 것은 아닙니다. 내부 타이어 완화 상태는 기존에 확인한 재시작 규칙대로 0으로 설정했습니다.

[세 조건 통합 그림](comparison_50_70_90_all.png)

| 조건 | 횡속도 RMSE (m/s) | 요레이트 RMSE (rad/s) | 롤 RMSE (°) | 피치 RMSE (°) |
| --- | ---: | ---: | ---: | ---: |
| 50 km/h · μ0.5 · 0° | 0.002890294 | 0.0007491053 | 0.007219587 | 0.0005342799 |
| 70 km/h · μ0.6 · 2.5° | 0.01018441 | 0.002406331 | 0.01019936 | 0.003685287 |
| 90 km/h · μ0.6 · 2.5° | 0.03800899 | 0.004014782 | 0.03869921 | 0.00741232 |

기존 모델 대비 70 km/h 횡속도 RMSE는 0.0096376 → 0.01018441 m/s로 약 5.7% 증가했고, 50 km/h 요레이트 RMSE는 0.0007372843 → 0.0007491053 rad/s로 약 1.6% 증가했습니다. 감소한 지표와 함께 이 차이도 그대로 기록했습니다.

| 조건 | 롤 최대값 CarSim / 모델 (°) | 10초 횡속도 CarSim / 모델 (m/s) | 10초 요레이트 CarSim / 모델 (rad/s) |
| --- | ---: | ---: | ---: |
| 50 km/h | 0.671046 / 0.716099 | -0.014586 / -0.014587 | -0.000146 / -0.000145 |
| 70 km/h | 2.467510 / 2.485814 | -0.072544 / -0.082168 | 0.198620 / 0.200867 |
| 90 km/h | 2.984145 / 3.032681 | -0.377589 / -0.394860 | 0.194746 / 0.196301 |

이전 모델 대비 비교는 각 MAT/JSON의 `rmse_change_from_previous_model`에 저장했습니다. `reduction_percent`가 음수이면 해당 지표의 오차가 증가한 것입니다.

초기 과도응답과 정상상태 차이가 남아 있으며, 모든 지표가 동시에 개선되었다고 해석하면 안 됩니다. 실제 수치와 그래프를 함께 확인해야 합니다. 210조건 전체 또는 마모 5종의 안정영역 일치를 검증한 것은 아닙니다. 기존 210조건 계산은 중단 상태입니다.

전체 3D 캐리어 회전 옵션은 세 조건 교차검증에서 롤·피치 오차가 증가하여 최종 모델에서 비활성화했습니다. 최종 결과는 모든 조건에 동일한 옵션을 사용하며, 조건별로 서로 다른 모델을 선택하지 않았습니다. 활성 옵션은 각 MAT/JSON의 `model_options`에 저장했습니다.

수치 구현/적분 검증은 [검증 JSON](numerical_verification.json), 전체 오차 지표는 [통합 JSON](comparison_report.json)에 있습니다.

- 50 km/h: [응답 그림](comparison_50kph_0.5mu_0deg.png) · [비교 MAT](comparison_50kph_0.5mu_0deg.mat)
- 70 km/h: [응답 그림](comparison_70kph_0.6mu_2.5deg.png) · [비교 MAT](comparison_70kph_0.6mu_2.5deg.mat)
- 90 km/h: [응답 그림](comparison_90kph_0.6mu_2.5deg.png) · [비교 MAT](comparison_90kph_0.6mu_2.5deg.mat)

MAT의 `ResponseComparison`에는 시간, 선택한 6개 응답, 네 코너 스프링/댐퍼 힘, 조건·오차 지표·해시만 포함됩니다. 힘 배열은 `[FL FR RL RR]` 순서의 4×N, 단위 N입니다. 원본 차량/타이어 입력, 전체 72채널, 모델 Q/T/c 구조체와 로컬 경로는 포함하지 않았습니다.

```matlab
S = load('comparison_90kph_0.6mu_2.5deg.mat');
R = S.ResponseComparison;
plot(R.time_s,R.carsim_response.roll_deg, ...
     R.time_s,R.independent_response.roll_deg,'--');
legend('CarSim','Revised model'); grid on;
xlabel('Time [s]'); ylabel('Roll angle [deg]');
```
