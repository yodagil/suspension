# 서스펜션 81모드 정상상태 lookup table

[**MAT 파일 다운로드**](https://raw.githubusercontent.com/yodagil/suspension/main/results/steady_state_lookup/steady_state_lookup_210x5x81.mat) · [필드·수렴 판정·MATLAB 조회 설명](../../steady_state_lookup/README_KO.md)

**210조건 × 타이어 마모 5종 × 서스펜션 81모드 = 85,050조합**을 모두 새로 시뮬레이션했습니다. 최초 60초 안에 미수렴한 2,520조합은 같은 모델·영 초기상태·판정 기준으로 최대 300초까지 추가 확인했습니다.

| 결과 | 조합 수 |
|---|---:|
| 수치 수렴 확인 | 83,274 |
| 수렴하고 마지막 구간의 안정 제약도 충족 (`usable`) | 63,698 |
| 수렴했으나 마지막 구간의 안정 제약 초과 | 19,576 |
| 300초 내 미수렴 | 977 |
| 상태 제한(hard guard)으로 종료 | 799 |
| 수치 NaN/Inf 실패 | 0 |

미수렴·상태 제한 종료의 정상상태 출력 1,776개는 **NaN**입니다. 수렴했으나 안정 제약을 넘은 값은 원래 수렴값과 판정 플래그를 함께 저장하고, `safe_*` 맵에서는 NaN으로 구분합니다. 결과를 보간하거나 빈 수렴값을 주변 값으로 채우지 않았습니다.

MAT 변수명은 **`STEADY_STATE_LUT`**입니다.

- 배열 크기: `6 × 5 × 7 × 5 × 81`
- 축 순서: 속도 · μ · 전륜 휠 조향각 · 타이어 마모 · 서스펜션 모드
- 주요 출력: `vc_ss` [m/s], `r_ss` [rad/s], `phi_ss` [rad]
- 숫자 축: 속도 `50:10:100`, μ `[0.5 0.6 0.7 0.8 0.9]`, 조향각 `0:0.5:3`
- 코너 순서: **FL · FR · RL · RR**
- 모드 순서: **`nnnn, nnns, nnnh, nnsn, nnss, nnsh, …, hhhh`** (`n → s → h`, RR이 가장 빠르게 변함)
- 스프링 강성 `[n s h]`: 전륜 `[30790 22161 36086]`, 후륜 `[30790 23632 35007]` N/m
- CDC 전류: 모든 코너·모드 **950 mA**

모드와 마모는 범주형 선택값입니다. 각 모드·마모를 선택한 뒤 속도·μ·조향각에 대한 맵을 사용하세요. 수렴 여부와 제약 충족 여부를 확인한 뒤 값을 사용해야 합니다.

각 조합은 초기 횡속도·요레이트·롤각 0에서 시작합니다. 같은 32상태 Full-Car/MF 모델과 기존 직접 시작 초기화를 유지했습니다. 수렴 판정은 동적 상태 29개의 최근 2초 변동폭·원시 RHS·평균 차이를 검사하며 연속 두 번 통과해야 합니다. 방향각·세계좌표는 수렴 판정에서 제외합니다. 이 결과는 지정한 초기조건에서의 수치 수렴이며, 모든 초기조건의 유일한 평형점이나 전역적 안정성의 증명은 아닙니다.

검증에는 모든 85,050행의 입력·모드·수렴 진단량, 원본 M-code와의 RHS/RK4 비교, 7초 전체 궤적 비교, 기존 `nnnn` 모드 1,050조합의 최초 5초 판정 일치, 수렴 후보 8개의 추가 10초 유지 확인, MAT 저장·재읽기와 인덱스 확인을 포함합니다. [검증 파일](validation/)

```matlab
D = load('steady_state_lookup_210x5x81.mat');
LUT = D.STEADY_STATE_LUT;
% 80 km/h, mu=0.9, 2 deg, 정상 타이어, nnnn:
value = [LUT.vc_ss(4,5,5,1,1), LUT.r_ss(4,5,5,1,1), LUT.phi_ss(4,5,5,1,1)]
valid = LUT.usable(4,5,5,1,1)
```
