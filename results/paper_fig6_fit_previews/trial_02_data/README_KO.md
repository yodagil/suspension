# Trial 02: 롤 하중 비교 모델

40 km/h 고정, 마찰계수 0.85, 전륜 조향각 0°/3.5°/7°의 실제 계산 결과입니다.
초기 격자는 41×55×31=69,905개이고, 시뮬레이션은 5초, RK4 시간 간격은 0.01초입니다.
GNU Octave에서 MATLAB 호환 M-code를 실행했습니다.

## 논문 원식과의 차이

이 결과는 논문 Figure 6의 정확한 재현이 아닙니다. 논문 식 (11)의 준정적
수직하중에 다음 롤 관성 반력을 추가한 **명시적인 비교 모델**입니다.

`D = m*h*ay + ms*g*hphi*sin(phi) - Ixx*pdot`

식 (4)와 이 반력에 동일한 `Ixx=700`을 사용한다는 관성 기준점 가정이 있습니다.
논문에는 관성 기준점과 필요한 모든 파라미터가 명확히 공개되어 있지 않습니다.
비교 모델에는 능동 현가력 없이 `ms=1300`, `hphi=0.35`, `Ks=1`,
Burckhardt 형상 `[1.28, 23.99, 0.52]`를 세 각도에 동일하게 사용했습니다.
Table 1의 공개 수치는 변경하지 않았습니다.
차속 고정은 외부 속도 유지의 근사이며, 구동 토크 및 결합 슬립 제어 모델은 아닙니다.

## MAT 파일과 그림의 의미

각 MAT의 `PAPER_STABILITY3D.result`에는 전체 초기 격자의 안정 판정이 있습니다.
`PAPER_STABILITY3D.region`은 그중 **정상 선회 상태 주변의 보수적인 내부 영역**입니다.
이 영역과 전체 안정 초기조건 집합은 서로 다릅니다.

내부 영역은 모든 각도에 같은 후보군과 최대 부피 목적을 적용한 8꼭짓점
격자 평행육면체입니다. 중심은 검증된 정상상태에서 각 축 격자 간격의 절반 이내에
놓이고, 정상상태를 내부에 포함합니다. 상태 간의 상관관계는 전단 변환으로 표현합니다.
논문에서 공개하지 않은 꼭짓점 선정 규칙을 대신하는 재구성 가정이며,
각도별 좌표 배율이나 수동 축소 계수는 사용하지 않았습니다.

| 조향각 | 전체 안정점 수 | 내부 롤각 범위 (rad) | 내부 부피 |
|---:|---:|---:|---:|
| 0° | 15,445 | −0.160000 ~ 0.160000 | 1.3653333333 |
| 3.5° | 15,537 | −0.106667 ~ 0.160000 | 0.6257777778 |
| 7° | 13,990 | 0.026667 ~ 0.133333 | 0.0568888889 |

초기 롤각 격자는 원래의 ±0.4 rad로 유지했습니다.
그림의 축 범위를 줄여 계산 결과를 잘라낸 것이 아닙니다.
원시 안정점의 롤각 범위는 각각 ±0.24, [−0.213333,0.24],
[−0.186667,0.213333] rad로, 그림의 보수적 내부 영역보다 큽니다.

## 검증 및 소스

- 동적 하중 대수·대칭·기존 식 회귀 검사 26개 통과.
- 선택한 꼭짓점 24개는 모두 실제 안정 격자점이며, 각 영역 내부 및 경계의 원본 불안정 격자점은 0개.
- 시간 간격 0.005초 재실행에서도 꼭짓점 24개와 정상상태 3개가 모두 안정.
- 이는 표본 격자에 대한 검증이며, 연속 상태공간 전체의 안정성 증명은 아닙니다.

`source`의 `paper_*.m` 세 파일은 실행 당시 소스 그대로입니다.
`run_full_grid.py`는 실제 실행 조건을 설정한 제어 코드이고,
`find_fixed_equilibria.m`은 정상상태 검증 코드입니다.
`build_equilibrium_inner.py`와 `build_equilibrium_sheared.py`가 내부 영역을 구성합니다.
내부 영역 구성과 그림 생성은 Python 후처리이며, 시뮬레이션 M-code와 구분됩니다.
제어·검증 스크립트의 `/workspace/suspension` 경로는 실행 환경 기준입니다.

기존 Full-Car 결과 및 중단된 210개 일괄 계산은 변경하거나 재개하지 않았습니다.
