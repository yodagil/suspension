# Trial 03: 0°에서 넓고 조향각이 증가하면 좁아지는 내부 영역

40 km/h 고정, μ=0.85, 조향각 0°/3.5°/7°를 다시 계산했습니다.
각 조건은 초기상태 69,905개(41×55×31), 5초, RK4 시간 간격 0.01초입니다.
GNU Octave에서 MATLAB 호환 시뮬레이션 M-code를 실행했습니다.

직전 Trial 02에서 추가했던 롤 관성 반력 항은 이번 모델에 사용하지 않습니다.
원래 식 (4)의 롤 동역학과 식 (11)의 준정적 수직하중을 사용합니다.
Table 1 값은 유지하며, 미공개 파라미터는 세 조건 모두 동일하게
`ms=1300`, `hphi=0.54`, `Ks=1`, Burckhardt 형상 `[1.28,23.99,0.52]`로 두었습니다.
`ms=m`, `hphi=h`는 모든 질량을 현가질량으로 보고 롤센터를 지면에 놓는 **가정**이며,
논문에서 공개한 파라미터가 아닙니다.

## 전체 안정점과 표시한 내부 영역의 차이

**이 그림은 보수적으로 선택한 내부 영역입니다. 전체 안정점 집합이나
논문 Figure 6의 정확한 재현 결과로 해석하면 안 됩니다.**

| 조향각 | 전체 안정점 수 | 전체 안정점 롤각 범위 | 선택한 내부 영역 롤각 범위 | 내부 영역 롤각 폭 |
|---:|---:|---:|---:|---:|
| 0° | 48,573 | −0.4 ~ 0.4 | −0.400000 ~ 0.400000 | 0.800000 |
| 3.5° | 49,517 | −0.4 ~ 0.4 | −0.293333 ~ 0.400000 | 0.693333 |
| 7° | 50,164 | −0.4 ~ 0.4 | −0.186667 ~ 0.400000 | 0.586667 |

전체 안정점 수는 감소하지 않습니다. 정상상태의 횡속도·요레이트에 초기 롤각만
바꾼 별도 검사에서도 ±0.4 rad가 모두 안정으로 남았습니다.
따라서 표시된 축소는 아래의 **공통 내부 영역 선정 규칙에 따른 결과**이며,
물리적 안정 경계 전체의 축소가 검증되었다는 뜻은 아닙니다.

각 MAT의 `PAPER_STABILITY3D.result`는 전체 격자의 원래 안정 판정을 담습니다.
`PAPER_STABILITY3D.region`은 그 안에서 선택한 8꼭짓점 내부 영역입니다.
원래 안정 판정과 좌표에 조향각별 배율을 적용하거나 마스크를 수정하지 않았습니다.

## 공통 내부 영역 선정 규칙

논문은 정확한 꼭짓점 선정 수치 규칙을 공개하지 않았습니다. 이번 비교에서는
다음 재구성 가정을 세 조향각에 동일하게 적용했습니다.

- 정상 선회 해를 구하고 국소 선형 안정성과 물리적 한계를 확인합니다.
- 내부 영역 중심은 정상상태에서 각 축 격자 간격의 절반 이내에 둡니다.
- 꼭짓점은 실제 안정 격자점 8개이며, 정상상태를 엄격히 내부에 포함합니다.
- 횡속도·요레이트·롤각의 상관관계는 격자 평행육면체의 전단으로 표현합니다.
- 횡속도 방향으로 지나치게 긴 형상을 배제하기 위해 공통 제약
  `(vc 폭/20) <= (r 폭/1.44)`를 적용합니다.
- 위 후보군에서 부피가 가장 큰, 원본 불안정 격자점을 내부나 경계에 포함하지 않는 영역을 선택합니다.

정규화 폭 `20 m/s`, `1.44 rad/s`와 비율 상한 `1.0`은 초기 격자에 따른
**기하학적 선택 가정**입니다. 논문의 공개 규칙이나 새로운 물리적 불안정 기준이 아닙니다.
세 조건에 동일한 제약을 적용하며 조향각별 수동 축소 계수는 없습니다.
롤각 폭 가중치는 0이고, 실제 선택 목적은 위 제한된 후보군 안의 최대 부피입니다.

## 검증과 실행 파일

선택한 24개 꼭짓점 모두 실제 안정 격자점이며, 각 내부 영역 및 경계의
원본 불안정 격자점은 0개입니다. 시간 간격 0.005초 재실행에서도
꼭짓점 24개와 정상상태 3개가 모두 안정 판정을 유지했습니다.
표본 사이 연속 상태공간 전체에 대한 안정성 증명은 아닙니다.

`source/paper_*.m` 세 파일은 실제 실행한 시뮬레이션 소스입니다.
`run_full_grid.py`는 공통 조건을 설정한 실행 제어 코드입니다.
`find_quasistatic_equilibria.m`은 정상상태를 구하고 검증합니다.
`build_equilibrium_inner.py`와 `build_equilibrium_sheared.py`는 Python 후처리입니다.
실제 내부 영역 실행 옵션은 `--max-vc-r-aspect 1`이며,
`--horizontal-roll-planes`나 0이 아닌 `--roll-span-power`는 사용하지 않았습니다.

그림은 모든 조건에 같은 직교 카메라(고도 11°, 방위각 −72°)를 사용합니다.
오른쪽 작은 그래프는 표시된 내부 영역의 실제 롤각 최솟값·최댓값입니다.
기존 Full-Car 결과 및 중단된 210개 일괄 계산은 변경하거나 재개하지 않았습니다.
