# MF 준정적 타이어와 동적 롤 반력 모델

`run_mf210_paper_roll.m` 하나로 평형점 계산, 안정성 분류, 국소 내부 영역 추출, 그림 저장까지 실행합니다. MATLAB R2016b 이상, 기본 MATLAB만 사용하며 최적화·제어 툴박스나 외부 함수는 필요하지 않습니다.

```matlab
run_mf210_paper_roll
files = run_mf210_paper_roll('my_results', false); % 그림 생략
```

기본 계산은 고정 속도 40 km/h, 마찰계수 0.85, 앞바퀴 조향각 0°, 3.5°, 7°입니다. 각 조향각에서 독립적인 초기 `[v_c,r,phi]` 격자 81×55×31 = 138,105개를 5 s 동안 검사합니다. `v_c=-10:0.25:10 m/s`, `r=(-27:27)×(0.8/30) rad/s`, `phi=(-15:15)×(0.8/30) rad`입니다. 초기 롤 각속도는 0이며, 안정 조건은 0.01 s마다 관측하고 그 사이를 20회 RK4 부분 단계(0.0005 s)로 적분합니다. 전체 M-code 계산은 오래 걸릴 수 있습니다.

모델은 Xiao 등의 논문(doi:10.1016/j.aei.2022.101764)의 차체 방정식과 원래 210조건 타이어 모델의 건강한 MF 힘 계수를 사용한 **5상태 준정적 타이어 모델**입니다. MF 힘 계수·수평/수직 쉬프트·마찰 타원·`mu/0.9` 배율은 유지합니다. 타이어 슬립각은 매 순간의 정확한 바퀴 좌표계 속도로 계산하고, 종방향 슬립률은 원래 쉬프트가 포함된 힘 식의 자유 구름 해 `kappa=-Shx`를 적용합니다. 따라서 종방향 힘이 0이 되는 것은 쉬프트를 삭제해서가 아니라 원래 식의 해를 사용한 결과입니다.

이 모델은 원래 210조건 모델의 타이어 이완 상태, 바퀴 회전 동역학, 필터 상태를 사용하는 18상태 모델과 다릅니다. 그 과도 동역학을 보존했다고 주장하지 않습니다. 논문의 대수적 타이어 모델 구성에 가까운 별도 재구성이며, 논문의 Burckhardt 타이어를 그대로 재현한 것도 아닙니다. 상태는 `[u,v_c,r,phi,p]`이고 고정 속도 설정에서 `udot=0`입니다.

차체 방정식은 유지하고 인쇄된 식 (11)에 다음 동적 롤 반력 법칙을 **명시적인 물리 확장**으로 적용합니다.

```text
D = Cphi*p + Kphi*phi + ms*g*hphi*(sin(phi)-phi)
```

기준 가정 `m=ms=1300 kg`, `h=hphi=0.54 m`에서는 일반식의 `(m*h-ms*hphi)*ay` 계수가 0입니다. 강성 `Kphi=43100 Nm/rad`, 감쇠 `Cphi=1400 Nm/(rad/s)`는 동일합니다. 고정 속도, 전체 질량의 현가 질량 가정, 롤 중심 높이, 5 s 관측 시간 등 재구성 설정을 논문에 모두 제시된 수치로 해석하면 안 됩니다.

각 조향각의 평형점은 저장된 좌표를 주입하지 않고 실행 중에 직접 구합니다. `p=0`에서 `[vdot,rdot,pdot]=0`을 중앙 차분 야코비안과 감쇠 Newton 방법으로 풀며, 직진에서 시작해 조향각을 최대 0.1°씩 증가시켜 같은 안정 분기를 추적합니다. 각 단계에서 고정 속도의 네 동적 좌표 `[v_c,r,phi,p]`에 대한 4×4 야코비안 고유값의 실수부가 모두 음수인지 검사하고, 수직하중 양수·요율·횡가속도 조건도 확인합니다. 전체 5상태 야코비안에는 고정 속도로 인한 영 고유값이 있으므로 국소 안정성 판단에서 그 좌표를 제외합니다. 이 절차는 추적한 분기의 국소 안정성을 확인하며 전역적인 평형점 유일성을 증명하지 않습니다.

각 `stable_point_40kph_0.85mu_{0,3.5,7}deg.mat`에는 다음 구조체가 들어갑니다.

- `PAPER_STABILITY3D`: 설정 `cfg`, 해석·모델 구분 `meta`, 전체 안정/불안정 분류와 최초 위반 원인 등 `result`.
- `EQUILIBRIUM`: 실제 5상태 평형점, 잔차, 4×4 야코비안, 고유값, 물리 조건 검사 결과.
- `INNER_REGION`: 유효성 `valid`, 8×3 꼭짓점 `vertices`, 6×4 면 `faces`, 체적 `volume`, 3×2 좌표 범위 `bounds`, MATLAB 1기반 인덱스 `grid_indices_1based`, 모든 최대 체적 동률 목록.

인덱스 순서는 `[vc_lo vc_hi r_lo r_hi phi_lo phi_hi]`이며 원래 좌표 순서는 `[v_c,r,phi]`입니다. `classification_{tag}deg.mat`에 분류와 평형점을 먼저 저장하므로 이후 영역 추출에 문제가 생겨도 분류 결과는 남습니다. 모든 MAT 저장은 `-v7` 형식이며 `equilibrium_continuation.mat`에는 전체 분기 추적 기록도 저장합니다.

`INNER_REGION`은 **해당 조향각 자체의 안정 평형점을 포함하고, 포함된 모든 격자점이 안정인 격자 정렬 직육면체 중 전역 최대 체적 영역**입니다. 평형점은 직육면체에 포함되어야 하지만 중심일 필요는 없습니다. 모든 롤 구간의 교집합과 단조 스택 직사각형 탐색으로 실제 좌표 간 거리의 곱을 최대화합니다. 최대 체적 동률은 같은 사전식 인덱스 순서로 선택하며 모든 동률을 저장합니다. 종횡비 제약, 조향각별 추가 롤 상한·축소율, 다른 조향각 영역의 포함 관계, 중첩 조건은 사용하지 않습니다. 평형점 추적은 분기를 정하는 과정이며 영역 선택에서 다른 조향각의 직육면체를 참조하지 않습니다.

이 직육면체는 논문 저자의 형상 추출법이나 전체 원시 안정 영역이 아닙니다. 포함된 **분류 격자점**의 안정성을 확인하며 그 사이 연속 상태까지 보증하지 않습니다. 영역 간 자연적인 중첩 관계도 주장하지 않습니다.

```matlab
plot_mf210_paper_roll('my_results','my_regions');
```

그림은 0°/3.5°/7°를 초록/노랑/파랑으로 한 좌표계에 겹쳐 실제 8개 꼭짓점과 6개 면, 12개 모서리를 표시합니다. 표시 순서는 `x=r`(축 방향 반전), `y=v_c`, `z=phi`이며 좌표값을 확대하거나 평행 이동하지 않습니다. 방위각 −72°, 고도각 11°의 직교 투영, 롤 표시 범위 ±0.3 rad, `v_c` 표시 범위 ±2 m/s를 공통으로 사용하고 PNG와 MATLAB FIG를 저장합니다. 계산 격자의 롤 범위는 ±0.4 rad입니다.

```matlab
run_mf210_paper_roll('smoke_results',false,true);
```

검증용 빠른 모드는 평형점 계산을 그대로 수행한 뒤 각 자체 평형점 주변에 동일한 작은 간격의 3×3×3 격자를 구성하여 0.02 s만 계산합니다. 이 모드는 생산용 영역의 중심이나 범위를 바꾸는 설정이 아니며 전체 계산을 대체하지 않습니다. 결과 메타데이터의 `validation_smoke_test`에 명시됩니다.

`build_local_equilibrium_cuboid.m`은 이미 분류한 마스크에 적용할 수 있는 독립 영역 함수입니다. 실행 파일 내부에도 동일한 함수가 포함되어 있으므로 단일 파일 실행에 별도 설치는 필요하지 않습니다. `source/`에는 실제 MF5 동역학 소스와 native C++ 소스를 수정 없이 보관하고 `provenance/`에는 식별 해시와 검증 결과를 제공합니다.
